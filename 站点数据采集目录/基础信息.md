## 2、首页与 SEO 数据

首页固定框架为 Hero、Status、Facts、Story、Release、Index。除 Hero 外，其余模块可根据游戏实际情况改写或禁用。完整模块数据另存 `首页探索模块.json`。

```json
{
  "site": {
    "gameName": "",
    "name": "",
    "shortName": "",
    "tagline": "",
    "description": ""
  },
  "seo": {
    "homeTitle": "",
    "homeDescription": "",
    "keywords": ""
  },
  "home": {
    "hero": {"enabled": true, "label": "", "title": "", "description": "", "actions": []},
    "status": {"enabled": false, "items": []},
    "facts": {"enabled": false, "items": []},
    "story": {"enabled": false, "title": "", "description": ""},
    "release": {"enabled": false, "title": "", "description": ""},
    "index": {"enabled": true, "title": "", "description": ""}
  }
}
```

SEO 要求：title 不超过 60 字符；英文 description 为 140–160 字符；keywords 不超过 100 字符。没有可靠值时禁用数据项或模块，不填 0，不编造。
